# Website INDESK (indesk.vn)

Trang tĩnh một file, ba thứ tiếng (VI / EN / 中文), theo INDESK Brand Guideline V1.0.

- `index.html` – toàn bộ nội dung, giao diện và bản dịch (bản dịch nằm trong đối tượng `T` cuối file).
- `assets/` – logo xuất từ bản vector CAD đã duyệt 19/10/2026, favicon.
- `assets/projects/` – ảnh phối cảnh dự án đã thu nhỏ cho web (bản gốc nằm ở 03_MARKETING/05_Case Studies & Portfolio).
- `CNAME` – tên miền cho GitHub Pages.
